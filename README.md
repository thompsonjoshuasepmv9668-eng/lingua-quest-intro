# Lingua Quest 产品介绍页

独立中文静态介绍页：三遍法听力、影子跟读、关卡地图与收藏展示。

仅包含公开 HTML/CSS/JavaScript、产品图片和一段示例音频，无需构建。
用浏览器打开 `index.html` 即可预览。

## GitHub Pages

在 Settings → Pages 选择 Deploy from a branch、main、/(root)。
根目录 `.nojekyll` 保留原生静态文件。
启用部署后，网址为：https://thompsonjoshuasepmv9668-eng.github.io/lingua-quest-intro/

## 意见反馈

自动邮件暂未开放，可复制意见或使用页面上的公开收件地址。
`feedback-config.js` 只允许填写部署完成的公开 HTTPS 接口 URL。
邮箱密码、SMTP 授权码、后端环境文件和后端服务不属于本仓库。
